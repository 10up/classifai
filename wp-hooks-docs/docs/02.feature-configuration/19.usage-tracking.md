# AI Usage Tracking

The AI Usage Tracking feature monitors your AI API spend in real time and lets you set soft and hard cost thresholds that trigger email alerts or automatically disable all AI features until the next billing period.

## Set Up via OpenAI

### 1. Create an OpenAI organisation Admin API key

The usage data is fetched from OpenAI's [Organisation Costs API](https://platform.openai.com/docs/api-reference/usage), which requires an **Admin API key** — not a regular project API key.

* Log into your [OpenAI account](https://platform.openai.com/).
* Navigate to **Organisation settings → Admin API keys**.
* Click **Create new key**, copy the value shown, and store it securely.

### 2. Configure settings under Tools > ClassifAI > Usage Tracking > AI Usage Tracking > Settings

* Enable the feature with the **Enable** toggle.
* Select **OpenAI** in the provider dropdown.
* Paste your Admin API key into the **Admin API Key** field.
* Optionally enter a **Project ID** to restrict cost data to a single OpenAI project.
* Set the **Refresh interval** (minimum 5 minutes, default 15 minutes). This controls how often the plugin polls the OpenAI API for updated cost data.
* Click **Save Settings**.

### 3. Review the Dashboard widget

After setup, a new **AI Usage Tracking** widget appears on the WordPress admin dashboard (`/wp-admin/index.php`). It shows three rolling cost totals:

| Metric | Description |
|---|---|
| **This month** | Costs from the first of the current month to now |
| **Year to date** | Costs from the first of the current year to now |
| **All time** | Cumulative costs across all tracked years |

Costs are fetched in the background on a recurring schedule powered by [Action Scheduler](https://actionscheduler.org/). The widget displays "Updating…" until the first fetch completes. Click **Refresh Usage Data** to trigger an immediate refresh.

> **Note:** If you share the same API key or project across multiple sites or applications, the costs shown reflect total API usage for that key/project — not only requests made through ClassifAI.

## Configure Spending Alerts

### Soft threshold (warning alert)

The soft threshold sends a one-time email alert per billing period when your spend crosses a defined amount. AI features continue to work normally.

* In the feature settings, expand the **Soft threshold (alert)** panel.
* Toggle **Enable soft threshold alert** on.
* Enter a dollar **Amount** (minimum $1.00) to trigger the alert.
* Choose a **Scope**: `Current month`, `Year to date`, or `All time`.
* Enter one or more comma-separated email addresses in the **Alert emails** field.
* Save settings.

When the threshold is crossed an admin notice is also shown on every admin page until the amount drops below the threshold.

### Hard threshold (disable AI features)

The hard threshold sends an email alert **and** disables all AI features for providers covered by your Usage Tracking configuration until you manually re-enable them.

* In the feature settings, expand the **Hard threshold (disable features)** panel.
* Toggle **Enable hard threshold** on.
* Enter a dollar **Amount** — must be higher than the soft threshold amount.
* Choose a **Scope**: `Current month`, `Year to date`, or `All time`.
* Enter one or more comma-separated **Alert emails**.
* Save settings.

When the hard threshold is exceeded:
* A `classifai_api_usage_hard_limit_reached` option is set in the database.
* All API calls through affected OpenAI features return a `classifai_hard_limit_reached` error.
* A dismissible error notice is shown on every admin page.
* To re-enable features, raise or disable the hard threshold in the settings and save.

## Hooks Reference

### Filters

#### `classifai_api_usage_refresh_interval`

Override the background refresh interval (in seconds) regardless of what is saved in the settings.

```php
/**
 * @param int $interval Refresh interval in seconds.
 * @return int
 */
add_filter( 'classifai_api_usage_refresh_interval', function ( int $interval ): int {
    // Refresh every 30 minutes instead of the configured value.
    return 30 * MINUTE_IN_SECONDS;
} );
```

### Actions

#### `classifai_api_usage_updated`

Fires after usage data has been fetched from the provider API and cached.

```php
/**
 * @param array $usage_data {
 *     @type float  $mtd          Current month-to-date cost.
 *     @type float  $ytd          Year-to-date cost.
 *     @type float  $all_time     All-time cost.
 *     @type string $currency     Currency code (e.g. 'usd').
 *     @type int    $last_updated Unix timestamp of the last successful fetch.
 * }
 * @param array $settings     Provider settings at the time of the fetch.
 * @param bool  $force_refresh Whether this was a manual force-refresh.
 */
add_action( 'classifai_api_usage_updated', function ( array $usage_data, array $settings, bool $force_refresh ): void {
    // e.g. push costs to a custom analytics table.
}, 10, 3 );
```

#### `classifai_api_soft_threshold_exceeded`

Fires when usage crosses the configured soft threshold. Use this to trigger custom notifications beyond the built-in email.

```php
/**
 * @param \Classifai\Providers\UsageTrackingProvider $provider    Provider instance.
 * @param array                                      $settings    Provider settings.
 * @param array                                      $usage_data  Current usage data.
 * @param float                                      $amount      The usage amount that triggered this action.
 */
add_action( 'classifai_api_soft_threshold_exceeded', function ( $provider, array $settings, array $usage_data, float $amount ): void {
    // e.g. send a Slack notification.
}, 10, 4 );
```

#### `classifai_api_hard_threshold_exceeded`

Fires when usage crosses the configured hard threshold (immediately before AI features are disabled).

```php
/**
 * @param \Classifai\Providers\UsageTrackingProvider $provider    Provider instance.
 * @param array                                      $settings    Provider settings.
 * @param array                                      $usage_data  Current usage data.
 * @param float                                      $amount      The usage amount that triggered this action.
 */
add_action( 'classifai_api_hard_threshold_exceeded', function ( $provider, array $settings, array $usage_data, float $amount ): void {
    // e.g. page an on-call engineer.
}, 10, 4 );
```
